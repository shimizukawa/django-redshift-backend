# Security policy

## Reporting a vulnerability

Please report software security vulnerabilities through GitHub's
[private vulnerability reporting](https://github.com/shimizukawa/django-redshift-backend/security/advisories/new).
Reports are private to the reporter and people with access to the advisory.
Include the affected version, reproduction steps, and potential impact.
Do not disclose vulnerability details in a public issue.

For ordinary bugs and questions, use
[GitHub Issues](https://github.com/shimizukawa/django-redshift-backend/issues).
For unacceptable behavior, follow [the Code of Conduct](CODE_OF_CONDUCT.md).
